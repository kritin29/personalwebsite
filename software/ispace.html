Ispace Software Solutions

A Chrome extension that automated insurance verification across three payer portals.

Role
Software Engineering Intern
Dates
May – Jul 2026
Location
Hyderabad, India
Stack
JavaScript · Chrome MV3

The code is proprietary and the screens contain patient data, so neither is shown here.

01Problem

Staff verified each patient's insurance by hand, portal by portal. The three payer portals present the same information in three different layouts, and the department handles 500+ patients a week.

02Solution

A Chrome Manifest V3 extension that reads each portal, pulls out the coverage details, and checks them automatically, inside the browser staff already use.

03How it works

  1. InputPatient list
  2. Visit3 payer portals
  3. ExtractPer-portal DOM extractors
  4. NormalizeOne JSON schema
  5. Match50-code reference set
  6. OutputVerified coverage
  • Per-portal DOM extractors in JavaScript turn three inconsistent page structures into a single JSON schema.
  • Each patient is matched against a 50-code insurance reference set.
  • Runs on top of the staff's existing portal sessions, so there is no new system to log in to.

04Results

85%less time per verification

500+patients a week

Takeaway

Most of the work was normalization: three portals described the same coverage three different ways.
