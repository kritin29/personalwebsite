FacultyWise

An AI grading co-pilot for professors: it pulls Canvas submissions, scores them against the rubric with GPT-4o, and posts reviewed grades back.

Role
Full-stack engineer
Team
2 people
Status
Piloted with 5 professors
Stack
React · TypeScript · Supabase · OpenAI · Inngest
  • Live app ↗

The code lives in a private team repository. Screenshots show the real app running on demo data; I'm happy to walk through the code.

01Problem

Professors grade large batches of Canvas submissions by hand, in every format from PDFs and scans to slides, spreadsheets, code, and phone photos. Writing rubric-aligned feedback for each one is slow.

02Solution

FacultyWise connects to a professor's Canvas account, turns every submission into something a model can read, and has GPT-4o score each rubric criterion and write feedback in the professor's voice. The professor reviews and edits, then posts back to Canvas in one click.

03My part

I built the grading engine and its 36-type file pipeline, the Inngest batch-grading queue, the Chrome extension, the integrations and encrypted OAuth token layer, and the database migrations behind them, plus most of the home dashboard and the AI assistant.

04How it works

  1. ConnectCanvas token, pasted or via the extension
  2. SyncCourses, assignments, rubrics, submissions
  3. Extract36 file types into text or images
  4. GradeGPT-4o scores every rubric criterion
  5. ReviewProfessor edits scores and feedback
  6. PostGrade, comment, and rubric back to Canvas
  • Canvas connects by personal token or through a Chrome MV3 extension that creates one in a click; tokens are encrypted with a key held in Supabase Vault and only readable server-side.
  • The file pipeline reads PDFs (with a vision fallback for scans), renders slides to images, turns spreadsheets into tables with formulas, and handles Word docs, code, and HEIC phone photos.
  • Grading a class runs on Inngest: one durable job fans out an event per submission, graded three at a time, with a fallback step so a job can never hang.
  • GPT-4o returns structured JSON per criterion (reasoning, score, feedback, confidence) at low temperature with a fixed seed, so regrades are stable; the server clamps and sums the scores.
  • Row-level security per professor, a 50-requests-per-hour AI rate limit, and sanitized submission HTML.

05Features 14

  • Canvas syncConnect by token or extension, then choose which courses to sync.
  • Three-pane graderCourse and assignment pickers, a student list with status and confidence, and the submission.
  • Any file formatViewer for text, PDFs, Word, images, code, and links, with tabs for multiple files.
  • One-click AI gradeScores the open submission per rubric criterion, with a confidence banner.
  • Grade allA background batch with a live progress counter that survives page reloads.
  • Interactive rubricRating pills or point inputs per criterion, auto-summed, with manual override and CSV import.
  • Feedback in your voiceAI comments written in the professor's own grading persona, fully editable.
  • Review triageLow-confidence or unreadable submissions are flagged before posting.
  • Post to CanvasGrade, comment, and rubric assessment written back in one click.
  • Grade button in CanvasThe Chrome extension adds a FacultyWise button to Canvas assignment pages.
  • AI assistantStreaming chat with file attachments, Google Drive picker, and voice input.
  • Document canvasEditable documents with AI edits, version history, Word export, and Send to Canvas.
  • Daily briefingAn AI-built priority task list from Canvas and connected tools.
  • Onboarding + personaGuided setup that installs the extension, syncs courses, and learns the grading style.
