ClaudePearl

A desktop and phone app for AI-assisted development, with persistent project memory, auto-loaded skills, and live control of Roblox Studio and Blender.

Role
Solo
Built
Jul 2026
Status
v1.5, in daily use
Stack

Private repository. Screenshots show the real app running on demo data.

01Problem

Building Roblox games with Claude Code meant sitting at the desk watching a terminal through long runs, finding out about usage limits by hitting them, and re-explaining project decisions from one session to the next.

02Solution

A thin layer over the official Claude Agent SDK. One local backend owns every session, and the desktop app and a phone web app are both clients of it, so a chat started at the desk continues on the phone.

03Why build it

By mid-2026, Claude Code already had memory, skills, and phone access. ClaudePearl rebuilds them around how I actually work as a solo game developer:

  • One session, any screen: a local backend owns every session, so several named sessions keep running and I can steer any of them from my phone, with push alerts when replies land.
  • Memory I control: decisions are saved on purpose with remember:, stored as structured data, summarized per session, and browsable, instead of notes the model picks for itself.
  • Predictable context: skills are picked by keyword score and capped at two per prompt, so I always know what was loaded and why.
  • Limits at a glance: context, the 5-hour and weekly windows, and cost stay on screen instead of behind a command.
  • Game-dev tooling: live connection checks for Roblox Studio and Blender, and an overnight agent that researches Roblox trends and pitches a buildable concept.

04How it works

  1. ClientsTauri desktop app + phone web app
  2. APIFastify REST API + a live WebSocket stream
  3. SessionsOne long-lived Agent SDK session per project
  4. MemorySQLite per project: decisions, summaries, messages
  5. ToolsMCP bridges to Roblox Studio and Blender
  • Each session starts with the project's last summary and its 15 most recent decisions injected into the prompt.
  • Skills are scored by keyword match against the prompt; only the top two are loaded, never the whole library.
  • Messages sent mid-turn are queued into the running session, so Claude can be steered while it works.
  • An overnight research agent runs headless with web-only tools, a turn cap, a usage check, and output validation before anything is saved.
  • Tool status is probed directly, so the app shows whether Studio and Blender are really connected.

  • In-app questionsAnswer Claude's clarifying questions right in the GUI.
